Теоретичні відомості

1. HTML (HyperText Markup Language)

Стандартна мова розмітки веб-сторінок. Вона описує структуру веб-сторінки за допомогою тегів.

2. CSS (Cascading Style Sheets)

Мова стилів, що відповідає за зовнішній вигляд та оформлення HTML-документів (кольори, шрифти, сітки layout).

3. Семантика HTML5

Використання семантичних тегів (таких як <header>, <nav>, <article>) покращує доступність сайту та його індексацію пошуковими системами.

4. Елементи форм

Форми збирають дані від користувачів через радіокнопки (radio), прапорці (checkbox), поля вибору (select) та текстові поля (input text).
